# How to write meaningful commit?

1. Start with an uppercase imperative verb, Such As: Add, Drop, Fix, Refactor, Bump
    For example:
        - Add: Create a capability e.g. feature, test, dependency.
            + Create Dim_order
            + Create Fact_staging
            + Add column_name
        - Drop: Delete a capability e.g. feature, test, dependency.
            + Drop time condition
            + Drop view dependency
        - Fix: Fix an issue e.g. bug, typo, accident, misstatement.
            + Fix some bug
            + Fix missing order_id
        - Optimize: A change that MUST be just about performance, e.g. speed up code.
            + Optimize sync time
        - Refactor: A change that MUST be just a refactoring patch
            + Refactor
